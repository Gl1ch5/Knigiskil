# Шаблоны диалога с пользователем

## 1. Разбор стиля + концепция

```
Стиль Дюма — это:
• стремительный приключенческий сюжет, интрига за интригой;
• много живых диалогов, остроумие, дуэли, погони, заговоры;
• благородные герои-друзья против коварных врагов;
• исторический фон (реальные события и лица на втором плане);
• главы заканчиваются крючком.

Концепция:
«<Название>» — <логлайн>.
<5–8 предложений сюжета без развязки>
Герой: … Антагонист: … Время и место: …

Подходит?
```

Варианты в AskUserQuestion: «Подходит (Рекомендуется)», «Изменить детали», «Предложи другой сюжет».

## 2. Вопрос про спойлеры

```
Можно ли показывать вам спойлеры — развязку, повороты и тайны — в плане книги?
```
- «Да, показывайте всё» — план целиком.
- «Нет, сохраните интригу» — показываю только завязку, названия частей и прогресс.

## 3. Остальные пункты (по одному или пачкой до 4)

| Пункт | Вопрос | Варианты |
|---|---|---|
| Объём | Сколько страниц? | 1000 / 2000 / 4000 (Рекомендуется) / другое |
| Части | Сколько частей/томов? | 4 / 8 (Рекомендуется) / 12 |
| Глава | Длина главы? | ~6 стр. / ~10 стр. (Рекомендуется) / ~15 стр. |
| Лицо | От какого лица? | 3-е, несколько героев (Рекомендуется) / 1-е, один герой |
| Финал | Какой финал? | Счастливый / Открытый / Трагический |
| Рейтинг | Возрастной рейтинг? | 12+ / 16+ (Рекомендуется) / 18+ |
| Автор | Имя автора в файле? | Псевдоним / Ваше имя / «Неизвестный автор» |

## 4. Финальная сводка

```
Итого:
Название: … | Автор: … | Объём: 4000 стр. (~7,2 млн знаков)
Стиль: … | Жанр FB2: … | Части: 8 | Глав: ~400 по ~10 стр.
Лицо: … | Финал: … | Рейтинг: … | Спойлеры: нет

Начинаем писать?
```

## 5. Отчёты по ходу работы

Коротко и без текста глав:
```
Часть 2 из 8 готова: главы 51–100, 1012 из 4000 страниц.
```
Если `spoilers_ok=false` — не пересказывай события, только цифры.
