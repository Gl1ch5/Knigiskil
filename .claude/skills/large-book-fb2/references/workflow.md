# Шаблоны диалога с пользователем

## 1. Первые вопросы (AskUserQuestion, до 4 за раз)

Спрашивай только то, чего нет в запросе. Первый вариант — рекомендуемый, с пометкой «(Рекомендуется)». Подбирай варианты под запрос: для «книги в стиле Кинга» не предлагай стили, а предложи завязки в его духе.

| Пункт | Вопрос | Варианты (пример) |
|---|---|---|
| Идея | Какая завязка ближе? | 2–3 придуманных логлайна под жанр/автора запроса |
| Лицо | От чьего лица? | 3-е, близко к герою / 1-е лицо / 3-е, несколько героев |
| Финал и рейтинг | Какой финал и рамки? | Выстраданный счастливый, 16+ / Открытый, 16+ / Горький, 18+ |
| Спойлеры | Показывать вам развязку и повороты в плане и отчётах? | Нет, сохраните интригу / Да, показывайте всё |
| Стиль (если не назван) | В какой манере писать? | Динамичная / атмосферная / ироничная / психологическая |
| Объём (если не назван) | Сколько страниц? | 300 / 500 / 1000 |

Автора не спрашивай: всегда «Павел М».

Если пользователь сказал «без вопросов» — пропусти и напиши одну строку: «Решил сам: стиль …, 500 стр. (3 части, 23 главы), 3-е лицо, финал …, 16+, без спойлеров».

## 2. Стиль + концепция → «Подходит?»

```
Стиль (паспорт):
• рассказчик: …   • тон: …   • фразы: …   • лексика: …
• диалоги: …   • описания: …   • темп: …   • приёмы: …
Запреты: …

«<Название>» — <логлайн>.
<5–8 предложений сюжета; без финала, если спойлеры запрещены>
Герой: <имя> — хочет …, но …  Антагонист: … — его правда: …
Ставки: …   Время и место: …
Объём: 500 стр. → 3 части, 23 главы по ~22 стр.

Пробный абзац:
<600–900 знаков в стиле книги>

Подходит?
```
Варианты: «Подходит (Рекомендуется)» / «Изменить детали» / «Другой сюжет».

## 3. Отчёты по ходу работы

Коротко, после каждой части:
```
Часть 1 из 3 готова: главы 1–8, 176 из 500 стр.
```
При `spoilers_ok=false` — только цифры, без событий.

## 4. Итог

```
Готово: books/<slug>/out/<slug>.fb2 (+ .fb2.zip)
«<Название>», Павел М. 507 стр. (913 тыс. знаков), 3 части, 23 главы. Проверка FB2 — ОК.
```
