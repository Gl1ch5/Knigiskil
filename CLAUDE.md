# Книги проекта

Этот проект — мастерская для нескольких книг. Каждая книга живёт в своей папке `books/<slug>/`. Все книги собираются в FB2 одним и тем же навыком `large-book-fb2`.

## Структура

- `books/<slug>/` — одна книга:
  - `book.json` — метаданные: название, автор, жанры, объём, стиль, `spoilers_ok`, аннотация, ключевые слова, рейтинг;
  - `bible.md` — библия: стиль, мир, персонажи, сюжетные линии, повороты, синопсис частей, главы, глоссарий. Единственный источник правды для писателя;
  - `plan/parts/part_NN.json` — части и главы (заголовки, краткие описания);
  - `plan/summaries/` — краткое содержание записанных блоков глав (память для продолжения);
  - `chapters/` — тексты глав (`cNNNN.txt` или `cNNNN-MMMM.txt`, первая строка главы — `# …`);
  - `out/` — собранный `.fb2` и `.fb2.zip`.
- `books/README.md` — список книг проекта. Его нужно обновлять при каждой новой книге.
- `.claude/agents/book-writer.md` — агент-писатель. Им пишутся главы любой книги проекта.
- `.claude/skills/large-book-fb2/` — навык и скрипты: `book_init.py`, `book_plan.py`, `book_status.py`, `book_build.py`, `book_validate.py`.

## Новая книга

Для книг проекта используется только навык `large-book-fb2` и агент `book-writer`. Другие навыки не привлекать, если пользователь не просит.

1. Уточни у пользователя жанр, эпоху, объём, сюжет, стиль-образец, рассказчика, тон, рейтинг, спойлеры. Если пользователь ответил на вопросы, не переспрашивай. Недостающее выбери сам по умолчанию и назови выбор в ответе.
2. Создай проект:
   ```bash
   python3 .claude/skills/large-book-fb2/scripts/book_init.py books/<slug> --title "…" --author "…" --pages N --genre <код>
   ```
   Коды жанров — в `.claude/skills/large-book-fb2/references/fb2_format.md`.
3. Заполни `bible.md` и `book.json`. В `book.json` поле `spoilers_ok` ставь по ответу пользователя: если он попросил держать сюжет в секрете, то `false`, и в чат план не выводится.
4. `book_plan.py skeleton books/<slug> --parts P --chapter-pages 10` создаёт части и главы. Затем заполни названия частей и синопсисы в `plan/parts/*.json`.
5. Запусти агента `book-writer` с указанием папки книги и номеров глав. Для длинных книг (больше 20 глав) пиши блоками частей, каждый блок — отдельным запуском агента, по порядку: summaries предыдущего блока нужны следующему.
6. Контроль и сборка: `book_status.py books/<slug>`, `book_build.py books/<slug> --zip`, `book_validate.py books/<slug>/out/<slug>.fb2`.
7. Добавь книгу в `books/README.md`.
8. Закоммить и запушь в designated-ветку. Незакоммиченные файлы книги блокируют остановку сессии, поэтому коммить черновики по мере записи.
9. Отправь пользователю готовый `.fb2` через SendUserFile.

## Правила

- Каждую книгу пиши только в её папке. Не меняй чужие книги без просьбы.
- Текст глав в чат не выводи; в ответе — статус, объём и путь к файлу.
- Для объёма используй скрипт подсчёта знаков, а не `wc -m` (в этой среде он считает байты).
- Оригинальный текст: в стиле автора-образца, но без копирования чужих текстов и персонажей.
- Коммиты и пуши — в designated-ветку `ccr-e9c34b5e-da65ai`; PR создаётся как обычно (см. инструкции сессии).
